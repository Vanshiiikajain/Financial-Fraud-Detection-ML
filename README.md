# 💳 Financial Fraud Detection & Model Monitoring System

A Machine Learning-based project for detecting fraudulent financial transactions and monitoring model performance.

## 📌 Project Overview
This project uses machine learning algorithms to identify potentially fraudulent credit card transactions. It also focuses on monitoring model performance through:

- Data Drift Detection
- Concept Drift Monitoring
- False Positive Rate (FPR) Monitoring
- Fraud Monitoring Dashboard

## 🤖 Machine Learning Models
The project explores multiple classification algorithms, including:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest
- Naive Bayes
- Decision Tree

## 📊 Dataset
**Credit Card Fraud Detection Dataset**

## 🛠️ Technologies Used

- Machine Learning
- Data Analysis and Visualization
